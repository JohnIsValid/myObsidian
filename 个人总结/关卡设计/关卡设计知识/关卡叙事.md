# 关卡叙事

> [!summary] 核心定义
> - 关卡叙事是通过关卡空间、场景物件、环境变化、视觉构图和玩家行动路径，向玩家传递故事、世界观、情绪和机制信息的叙事方式。
> - 它不主要依赖台词或文本直接告知，而是更多通过空间、场景、物件和玩家行动，让玩家在观察、探索、行动和推理中理解信息。
> - 好的关卡叙事不是“把故事摆在场景里”，而是让场景本身成为故事、情绪、玩法和世界逻辑的一部分。

## 1. 什么是关卡叙事

- 叙事可以通过多种手段完成，例如：
  - 语言叙事；
  - 文字叙事；
  - 关卡叙事。
- 关卡叙事强调“通过关卡进行叙事”。
- 它尤其依赖场景中的事物、空间结构和玩家行动过程来传达信息。
- 这些信息可以帮助玩家：
  - 更了解游戏世界；
  - 更理解角色处境；
  - 更容易沉浸到当前场景；
  - 理解玩法机制和行动目标。

### 1.1 关卡叙事与环境叙事的区别

- 在本文语境中，可以把环境叙事看作关卡叙事的一部分。
- **环境叙事**更强调通过场景细节讲故事。
  - 例如：尸体、血迹、破损家具、涂鸦、遗留物、生活痕迹。
  - 玩家通过观察这些环境细节，推断“这里曾经发生过什么”。
- **关卡叙事**在本文中的范围更广。
  - 它不仅包含环境叙事，还包括路径指引、节奏控制、玩法教学、空间压迫感、镜头构图和任务前后变化。
  - 玩家不只是“看懂故事”，还会因为场景叙事而改变行动、路线选择和情绪判断。
- 可以简单理解为：
  - 环境叙事偏向“场景如何讲故事”。
  - 关卡叙事偏向“关卡如何通过空间、玩法和环境共同传达信息”。
- 这个区分不是唯一标准定义，而是为了方便关卡设计复盘和实践使用。

### 1.2 房间示例：如何从场景读出信息

- 场景描述：
  - 房间里有床、桌子、电脑和书架。
  - 天花板上除了普通白炽灯外，还有五六个用细钢丝悬挂着的飞机模型。
  - 墙壁贴着蓝色壁纸，壁纸上有严重掉色的火箭涂鸦。
  - 地板铺着深蓝色毛绒地毯，看起来很容易落灰。
  - 床铺和凳子上散落着男孩子的衣物。
  - 窗户前的桌子上除了电脑，还有一个组装到一半的飞机模型，周围散落着零件和工具。
- 玩家可以推断出的信息：
  - 这是一个卧室。
  - 房间主人是一个男孩子。
  - 主人可能处于上大学前的年龄段。
  - 主人喜欢航天或飞机模型相关的内容。
  - 主人偏好蓝色，这种偏好可能与航天兴趣有关。
- 这个例子的关键点：
  - 玩家并没有被直接告知这些信息。
  - 信息来自物件组合、空间布置、色彩偏好和生活痕迹。
  - 玩家通过观察和推理，主动完成了对角色的理解。
- 结论：
  - 这种“通过场景让玩家读懂信息”的方式，就是关卡叙事。

## 2. 关卡叙事的好处

- 在讨论关卡叙事的优势之前，可以先对比语言叙事和文字叙事的局限。

### 2.1 语言叙事的局限

- 常见形式：
  - CG；
  - 旁白；
  - 语音。
- 优势：
  - 接受成本低，玩家只需要听或看即可理解。
  - 信息传达直接，容易被玩家接受。
- 局限：
  - 大多数内容通常只播放一次。
  - 内容较长时，玩家容易失去耐心。
  - 玩家通常无法自由快进，或选择只听某一段。
  - 即使可以再次观看，重复体验的效果也会大打折扣。

### 2.2 文字叙事的局限

- 常见形式：
  - 日记本；
  - 便条；
  - 邮件。
- 优势：
  - 可以反复查看。
  - 适合记录背景信息和补充设定。
- 局限：
  - 文字本身容易让部分玩家感到疲惫。
  - 有些玩家不会主动阅读文本。
  - 文本内容本身可能很难被玩家发现。
  - 在当代游戏中，除非玩法本身要求玩家寻找和收集文本，否则不适合把关键玩法信息或重要剧情完全放在文本里。
- 需要注意的是，文字叙事并非低效，只是更依赖玩家阅读意愿、文本质量和游戏类型。

### 2.3 直接叙事的共同问题

- 语言叙事和文字叙事都更接近直接叙事。
- 直接叙事的特点：
  - 目的性明确；
  - 信息传递直观；
  - 能让玩家快速得到结论。
- 直接叙事的风险：
  - 容易显得机械；
  - 容易打断玩家对世界的沉浸；
  - 如果过度依赖，会让剧情、玩法或设定说明显得无聊。

### 2.4 关卡叙事的优势

- 关卡叙事更接近间接叙事。
- 它不是通过语音或文字直接表达，而是通过图形、空间、物件和环境变化让玩家感受出来。
- 好的关卡叙事通常更容易被玩家接受，因为它隐藏在玩家本来就要经历的探索和行动之中。
- 主要优势包括：
  1. 丰富游戏玩法。
  2. 提升玩家沉浸感和代入感。
  3. 让玩家在主动发现信息时获得成就感。
  4. 降低叙事的强目的性和说教感。
  5. 能在玩家移动、观察和探索过程中，随时向玩家传递信息。

> [!warning] 使用关卡叙事时的限制
> - 关卡叙事并不是完美方案，因为它不是强制且直接的信息传达方式。
> - 需要考虑玩家屏幕是否足够大：如果屏幕太小，玩家可能看不清场景细节。
> - 需要考虑目标玩家是否愿意观察和思考：有些玩家群体并不愿意花精力理解精心设计的环境信息，因此这类游戏不适合大量依赖关卡叙事。
> - 需要考虑信息优先级：如果某个信息是玩家必须理解的核心规则，就不能只依赖非常隐晦的环境暗示。

## 3. 关卡叙事的作用

### 3.1 讲述故事

- 作用：
  - 通过环境状态、物件摆放、破坏痕迹或角色遗留物，补充讲述场景背后的故事。
- 玩家体验：
  - 玩家不是被动听故事，而是像侦探一样从痕迹中拼出故事。
- 设计要点：
  - 关键痕迹需要足够清晰。
  - 痕迹之间要能形成因果关系。
  - 不要只堆放“看起来有故事”的杂物，而要让物件之间互相解释。
- 示例图：
  - ![[Pasted image 20260413134842.png]]
- 图例说明：
  - 场景中的尸体、床铺、房间破损状态和角色当前视角，共同暗示这里曾经发生过事件。
  - 玩家可以通过物件状态判断环境背景，而不是只依赖文字说明。

### 3.2 情绪引导

- 作用：
  - 通过空间、灯光和氛围变化引导玩家情绪。
- 示例：
  - 从阴暗到光明的变化，例如《古墓丽影》（2013，常被玩家称为《古墓丽影9》）中的情绪推进。
- 玩家体验：
  - 阴暗、狭窄、低可见度会带来压迫感和不安感。
  - 明亮、开阔、可见度高的空间会带来释放感和安全感。
- 设计要点：
  - 情绪变化最好与玩家当前目标、剧情阶段或危险等级一致。
  - 如果情绪变化没有原因，玩家会感觉场景只是视觉风格变化，而不是叙事变化。
- 示例图：
  - ![[Pasted image 20260413134920.png|345]]

- 图例说明：
  - 通过明暗、空间压迫和环境危险感，可以让玩家在进入场景时先产生紧张情绪。
  - 如果后续从压抑空间进入明亮空间，就能形成明显的情绪释放。

### 3.3 提升沉浸感

- 作用：
  - 让世界更可信。
  - 让玩家更容易相信自己正在进入一个真实存在的空间。
- 玩家体验：
  - 当场景细节符合世界逻辑时，玩家会觉得这个地方不是临时搭出来的关卡，而是一个“曾经有人生活、工作或战斗过”的地方。
- 设计要点：
  - 场景中的物件应该符合地点功能。
  - 破损、脏污、摆放和使用痕迹要符合世界观。
  - 细节不需要多，但需要能说明问题。
- 示例图：
  - ![[Pasted image 20260413135011.png]]
- 图例说明：
  - 昏暗走廊、垃圾、封闭店铺和杂乱环境共同强化了场景的衰败感。
  - 这些细节让空间看起来更像真实存在的地点，而不只是单纯的通道。

### 3.4 路径指引

- 作用：
  - 利用血迹、灯光、地标或场景构图，引导玩家判断前进方向。
- 示例：
  - 《生化危机》中的血迹。
  - 游戏里的重要地标。
- 玩家体验：
  - 玩家会以为自己是在主动观察和判断路线，而不是被 UI 强行指路。
- 设计要点：
  - 指引信息要与世界逻辑结合。
  - 重要路径最好拥有多个指引线索，例如灯光、颜色、动态物体和地标同时辅助判断。
  - 不要让所有方向都拥有同等强度的视觉吸引力，否则玩家会迷路。
- 示例图：
  - ![[Pasted image 20260413135526.png|275]]
- 图例说明：
  - 灯光、血迹、明显地标或路径上的高亮区域，都可以自然吸引玩家视线。
  - 这类指引比单纯箭头更有沉浸感，但需要保证玩家能看见并理解。

### 3.5 暗示与提示

- 作用：
  - 通过异常痕迹预告危险、敌人、区域主题或后续事件。
- 示例：
  - 地上的粘液预示着异形巢穴。
- 玩家体验：
  - 玩家会在真正遭遇危险前先产生预期，从而提高紧张感。
- 设计要点：
  - 暗示不能太随机，必须与后续事件形成对应关系。
  - 如果暗示永远没有兑现，玩家会逐渐不再相信场景线索。
  - 如果所有危险都没有预兆，玩家会觉得失败不公平。
- 示例图：
  - ![[Pasted image 20260413135658.png|460]]
- 图例说明：
  - 异常材质、粘液、阴暗区域和低可见度，都可以暗示玩家前方可能存在危险。
  - 这类信息能让玩家提前调整心态和行为。

### 3.6 游戏教学

- 作用：
  - 通过环境布置和危险提示，让玩家在场景中自然学习玩法规则。
- 示例：
  - 《半条命2》Ravenholm，常译为“莱温霍姆”或“拉文霍姆”的相关关卡。
- 玩家体验：
  - 玩家不是被教程文字要求“你应该这么做”，而是在场景中发现“原来这样可以解决问题”。
- 设计要点：
  - 教学场景要先给玩家安全观察的机会。
  - 再给玩家低风险尝试的机会。
  - 最后再把学到的规则放进真实挑战中。
- 示例图：
  - ![[Pasted image 20260413135715.png|286]]
  - ![[Pasted image 20260413135727.png|312]]
- 图例说明：
  - 血迹、敌人位置、机关结构和可交互物件共同构成教学信息。
  - 玩家通过观察这些环境线索，可以理解某种武器、陷阱或互动方式的用途。

### 3.7 玩法内容

- 作用：
  - 让叙事元素本身成为玩法的一部分，使玩家在互动中理解环境、机制或目标。
- 玩家体验：
  - 玩家不是先理解故事再进行玩法，而是在玩法过程中逐渐理解故事。
- 设计要点：
  - 叙事物件最好能影响玩家决策。
  - 如果叙事内容和玩法完全无关，玩家可能会把它当成无意义装饰。

  - 场景中的破洞、遮挡和光照不仅制造氛围，也可能影响玩家探索、判断和前进路线。

## 4. 关卡叙事的设计原则

### 4.1 可读性优先

- 原则：
  - 玩家必须能看懂关卡想表达的核心信息。
- 判断方式：
  - 如果玩家看不到、看不清或看不懂，这个叙事信息就等于没有传达。
- 设计建议：
  - 关键物件需要在构图、光照、颜色或空间位置上更突出。
  - 重要信息不要只藏在极小、极暗或极偏的位置。

### 4.2 重点突出

- 原则：
  - 一个场景不应该同时表达过多同等重要的信息。
- 问题：
  - 到处都是细节，玩家反而无法判断哪里重要。
- 设计建议：
  - 给关键叙事物件留出视觉空间。
  - 用灯光、颜色、动线和遮挡关系压低次要信息的存在感。

### 4.3 与玩法结合

- 原则：
  - 最好的关卡叙事不只是装饰，而是会影响玩家行动。
- 示例：
  - 血迹不只是说明有人受伤，也可以引导玩家前往危险区域。
  - 破损墙体不只是表现场景破败，也可以暗示这里能被破坏或穿越。
- 设计建议：
  - 让叙事信息尽量与路线、危险、奖励、机制或任务目标发生关系。

### 4.4 避免过度解释

- 原则：
  - 关卡叙事的魅力来自玩家主动发现。
- 问题：
  - 如果每个细节都用文字解释，玩家就失去了推理空间。
- 设计建议：
  - 对必须理解的信息，可以用多重线索加强。
  - 对补充性的背景信息，可以保留一定留白。

### 4.5 符合世界逻辑

- 原则：
  - 场景线索必须看起来属于这个世界，而不是为了提示玩家而强行摆放。
- 判断方式：
  - 玩家能否相信这个物件本来就应该出现在这里？
  - 玩家能否理解这个痕迹为什么会形成？
- 设计建议：
  - 先确定地点功能，再决定场景物件。
  - 先确定事件经过，再决定痕迹和破坏状态。

### 4.6 形成前后反馈

- 原则：
  - 玩家行为应该尽量在环境中留下变化。
- 作用：
  - 让玩家感觉世界在回应自己。
  - 让任务进展不只体现在 UI 和任务列表里，也体现在关卡状态中。
- 示例：
  - 完成任务前后，NPC、灯光、封锁、敌人分布或场景破坏状态发生变化。

## 5. 关卡叙事的常用手段

### 5.1 控制信息密度

- 原则：
  - 叙事信息需要控制数量。
  - 到处都是叙事信息，等于没有叙事重点。
- 为什么有效：
  - 玩家注意力有限，只会优先关注最明显、最异常、最有用的信息。
- 使用风险：
  - 信息太少会让场景空洞。
  - 信息太多会让玩家无法判断重点。
- 设计目标：
  - 让关键叙事信息更突出。
  - 避免玩家被过多细节淹没。

### 5.2 建立统一标准

- 原则：
  - 创建统一的关卡空间标准，帮助玩家建立判断经验。
- 示例标准：
  - 多宽的空间可以通过。
  - 多窄的空间不能通过。
  - 多近的距离可以跳过去。
  - 多远的距离跳不过去。
- 为什么有效：
  - 玩家会在重复体验中学习规则，并用这些规则预测后续关卡。
- 使用风险：
  - 标准不统一会让玩家误判，进而觉得关卡不公平。
- 设计目标：
  - 让玩家通过场景本身理解规则，而不是每次都依赖文字或语音提示。

### 5.3 利用空间感受

- 可使用的空间类型：
  - 低矮的空间；
  - 高耸的空间；
  - 狭长的空间；
  - 多直角弯的空间；
  - T 形路；
  - Y 形路。
- 为什么有效：
  - 空间尺度会直接影响玩家的安全感、方向感和探索欲望。
- 使用风险：
  - 如果空间变化只追求视觉效果，而不服务情绪或玩法，玩家可能感受不到设计目的。
- 设计目标：
  - 用空间变化影响玩家心理和行动节奏。

### 5.4 制造变化

- 可使用的变化类型：
  - 完成任务前后的变化；
  - 完成某个关键节点后的变化。
- 为什么有效：
  - 玩家会通过环境变化感受到自己的行为产生了影响。
- 使用风险：
  - 如果变化太弱，玩家可能注意不到。
  - 如果变化太突兀，玩家可能觉得缺少因果关系。
- 设计目标：
  - 让关卡状态本身参与叙事。

### 5.5 制造对比

- 可使用的对比方式：
  - 阴暗与晴朗；
  - 封闭与开阔；
  - 危险与安全；
  - 整洁与破败；
  - 静止与混乱。
- 为什么有效：
  - 对比能让玩家更明确地感受到情绪变化和阶段变化。
- 使用风险：
  - 对比过于频繁会削弱冲击力。
  - 对比缺少铺垫会显得生硬。
- 示例：
  - 《古墓丽影》（2013，常被玩家称为《古墓丽影9》）中先阴暗、后晴朗的环境变化。

### 5.6 使用灯光

- 可控制的灯光要素：
  - 灯光强弱；
  - 是否有灯光；
  - 灯光方向；
  - 光源位置。
- 为什么有效：
  - 玩家天然会被明亮区域、移动光源和高对比区域吸引。
- 使用风险：
  - 如果所有地方都很亮，就失去了指引重点。
  - 如果关键区域太暗，玩家可能错过重要信息。
- 设计目标：
  - 引导玩家一步一步判断该往哪里走。
  - 强化安全、危险、神秘或压迫等氛围。

### 5.7 使用色彩

- 色彩可以表达：
  - 不同情绪；
  - 不同功能；
  - 安全或危险；
  - 是否可以交互。
- 为什么有效：
  - 玩家会逐渐把特定颜色与特定功能或情绪建立联系。
- 使用风险：
  - 颜色规则不统一会让玩家困惑。
  - 过度依赖颜色可能影响色弱或色盲玩家的识别。
- 设计目标：
  - 帮助玩家快速识别环境信息和交互信息。

### 5.8 增加细节

- 可使用的细节类型：
  - 模型细节；
  - 场景粒子特效，例如雾气、落叶；
  - 模型上的贴画；
  - 屏幕特效；
  - 后处理效果。
- 为什么有效：
  - 细节可以让场景看起来有历史、有使用痕迹、有世界逻辑。
- 使用风险：
  - 细节过多会变成视觉噪音。
  - 与主题无关的细节会削弱叙事表达。
- 设计目标：
  - 提升环境可信度。
  - 补充场景背后的故事信息。

### 5.9 使用天气与时间

- 可使用的天气和时间状态：
  - 雨天；
  - 暴风雨天；
  - 雪天；
  - 晴天；
  - 黄昏；
  - 半夜。
- 为什么有效：
  - 天气和时间会改变空间的情绪，也会改变玩家对危险和安全的判断。
- 使用风险：
  - 如果天气变化只为了好看，而不影响情绪、视线或玩法，就容易变成装饰。
- 设计目标：
  - 改变玩家对同一空间的情绪感受。
  - 帮助建立关卡阶段、危险等级或剧情氛围。

### 5.10 控制视线

- 示例：
  - 模糊的视线可以带来不安感。
- 为什么有效：
  - 玩家看不清时，会自然产生紧张、谨慎和探索欲。
- 使用风险：
  - 视线限制过强会造成挫败感。
  - 如果玩家看不见关键危险，会觉得失败不公平。
- 设计目标：
  - 限制玩家信息获取。
  - 强化紧张、未知或恐惧氛围。

### 5.11 使用孔洞

- 示例：
  - 墙面、地面或结构中的孔洞可以预示不安。
- 为什么有效：
  - 孔洞暗示“另一侧存在未知空间”，容易让玩家产生危险预期。
- 使用风险：
  - 如果孔洞既不能观察、也不能互动、也没有叙事意义，就会变成无效装饰。
- 设计目标：
  - 暗示未知空间、潜在危险或环境破坏。

### 5.12 使用形状

- 常见形状：
  - 圆形；
  - 方形；
  - 三角形。
- 为什么有效：
  - 不同形状会带来不同的视觉暗示和心理感受。
- 设计方向：
  - 圆形通常更容易让人联想到柔和、完整或安全。
  - 方形通常更容易让人联想到稳定、秩序或人工感。
  - 三角形通常更容易让人联想到尖锐、危险或攻击性。
- 使用风险：
  - 形状带来的心理感受会受到美术风格、场景语境、颜色和动态表现影响。
  - 形状表达通常比较隐性，不能单独承担关键叙事信息。

### 5.13 使用镜头

- 特点：
  - 镜头是一种较特殊的关卡叙事手段。
- 示例：
  - 《生化危机2》的镜头可以通过压迫构图和视角限制，强化里昂的脆弱感、被威胁感和处境不安。
- 为什么有效：
  - 镜头可以通过视角、距离、遮挡和构图改变玩家对角色处境的理解。
- 使用风险：
  - 镜头控制过强可能削弱玩家操作感。
  - 如果镜头表达与玩家操作需求冲突，会影响体验。
- 设计目标：
  - 通过构图、视角和画面压迫感改变玩家对角色处境的理解。

## 6. 关卡叙事设计检查表

| 检查项 | 核心问题 | 设计目的 |
| --- | --- | --- |
| 信息是否清晰 | 玩家能否看懂这个场景想表达什么？ | 保证叙事有效传达 |
| 重点是否突出 | 关键物件是否被杂物、光照或构图淹没？ | 避免视觉噪音 |
| 是否服务玩法 | 这个叙事信息是否会影响玩家路线、判断或决策？ | 让叙事不只是装饰 |
| 是否符合世界观 | 场景布置是否合理可信？ | 维持沉浸感 |
| 是否存在因果 | 玩家能否理解痕迹是如何产生的？ | 强化故事逻辑 |
| 是否有前后反馈 | 玩家完成任务后，环境是否发生变化？ | 让世界回应玩家行为 |
| 是否有信息层级 | 关键、次要和背景信息是否区分明确？ | 降低理解成本 |
| 是否避免过度解释 | 有没有给玩家留下观察和推理空间？ | 提升发现感和成就感 |
| 是否适合目标玩家 | 目标玩家是否愿意观察、探索和思考？ | 避免设计与受众错位 |
| 是否有备用提示 | 必须理解的信息是否有多重线索支持？ | 防止玩家错过关键信息 |

## 7. 速查总结

| 维度 | 关卡叙事关注点 | 设计目标 |
| --- | --- | --- |
| 信息 | 场景物件、痕迹、空间变化 | 让玩家自行读懂故事和规则 |
| 情绪 | 灯光、色彩、天气、视线 | 引导玩家情绪变化 |
| 路径 | 地标、血迹、光源、构图 | 帮助玩家判断前进方向 |
| 机制 | 统一标准、环境反馈、玩法元素 | 让玩家自然学习和理解玩法 |
| 沉浸 | 细节、可信空间、世界反馈 | 让世界更真实、更有代入感 |
| 原则 | 可读性、重点、世界逻辑、玩法结合 | 让叙事既能被理解，也能服务体验 |

## 8. 写作与设计上的后续完善方向

- 可以继续补充更完整的游戏案例分析：
  - 一个正面案例：说明它如何通过场景传递故事、情绪和玩法信息。
  - 一个反面案例：说明它为什么让玩家看不懂、走错路或失去沉浸感。
- 可以把每个案例拆成三个部分：
  1. 玩家看到了什么？
  2. 玩家会如何理解？
  3. 这个设计对玩法或情绪产生了什么影响？
- 可以继续整理成自己的关卡设计模板：
  - 场景目标；
  - 玩家情绪；
  - 关键信息；
  - 指引手段；
  - 叙事物件；
  - 任务前后变化；
  - 玩家可能误解的地方。
