#关卡白盒

---
此白盒工程文件是UE4上的一款免费材质包，其主要作用是材质上有刻度可以清晰看出距离关系，并在搭建白盒时对齐模型，并且有自定义材质颜色的功能使其可以区分白盒中不同模型的功能性以及场景的指示性；

---

# 文件规范

## 材质文件夹
所有和关卡材质相关内容都应放在LevelDesignMat文件夹中；
![[Pasted image 20260413133330.png]]
**子材质**直接放在**LevelDesignMat**文件夹中；

| **文件类型** | **材质代号** | **材质名称** | 最终名称         |
| -------- | -------- | -------- | ------------ |
| MI_      | C_       | Animals  | MI_C_Animals |

| 材质类型 | **代号** |
| ---- | ------ |
| 角色   | C      |
| 环境   | E      |
| 玩法   | G      |

**原生材质**放在**Materials**中；
**物理材质**放在**PhyMat**中；
 **材质函数**放在**TechArt**中；
**2D贴图**放在**Textures**中；

## 模型文件夹

所有模型都应放在LevelMesh文件夹中；

|**文件类型**|模型名称|模型体积|最终名称|
|---|---|---|---|
|SM_|Case_|L|SM_Case_L|

|模型体积|**代号**|
|---|---|
|小|S|
|中|M|
|大|L|

## 关卡文件夹

所有的关卡都应放在Maps文件夹中；

## 角色文件夹

所有角色相关的蓝图和资产都应放在ThirdPerson文件夹中；
![[Pasted image 20260413133523.png]]
# 材质规范

## 子材质参数
基本的子材质，可以由此演变出其他材质颜色；
![[Pasted image 20260413133641.png]]
## 子材质可控参数

| 参数名称          | 效果    |
| ------------- | ----- |
| BaseColor     | 基本颜色  |
| GridClow      | 一米线亮度 |
| LineColor（1m） | 一米线颜色 |
## 材质名称举例

| MI_C_Animals  | 中立生物的材质                     |
| ------------- | --------------------------- |
| MI_C_Enemy    | 敌人的材质                       |
| MI_C_NPC      | NPC的材质                      |
| MI_E_Grass    | 可行走混凝土地面的材质                 |
| MI_E_Grass    | 可行走植被覆盖区域的材质                |
| MI_E_Sand     | 可行走沙地区域的材质                  |
| MI_E_Stone    | 可行走石头的材质                    |
| MI_E_Water    | 水材质                         |
| MI_E_Wood     | 木材质                         |
| MI_G_Climb    | 特殊可攀爬区域的材质                  |
| MI_G_GamePlay | 玩法内容的材质                     |
| MI_G_Treasure | 可直接搜集内容的材质（包括但不限于宝箱，矿物，食材等） |
