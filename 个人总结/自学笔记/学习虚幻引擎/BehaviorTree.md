## 优先级编号

- 行为树中，优先级高的先执行，优先级低的后执行；
    
- 所有生效节点中，左侧优先级高于右侧，上方优先级高于下方；
    
- 行为树中所有生效的节点都会有一个唯一编号作为自己的优先级，该编号被称为“优先级编号”，如下图所示；
    
    ![[Pasted image 20260415142230.png]]
    
    - 行为树的逻辑会从0开始；
    - 行为树中未生效节点的优先级编号会被统一标记为-1；

## 上下级关系

- 上下级关系是指行为树中，有直接连线关系的主节点之间，优先级最高的为上级，其余节点为下级，如下图所示；

![[Pasted image 20260415142244.png]]

# 执行选择节点

## **Sequence节点**

![[Pasted image 20260415142252.png]]

- 依次执行下级节点；
- 若下级的所有节点都返回 Succeeded，则Sequence节点返回 Succeeded；
- 若任何一个下级节点返回 Failed，则停止执行后续下级节点，且Sequence节点返回 Failed；
- 若Sequence 节点下方没有任务节点，返回 Failed；

## **Selector节点**

![[Pasted image 20260415142300.png]]

- 从左到右依次选择执行下级节点；
- 若任何一个节点返回 Succeeded，则停止执行后续下级节点，且Sequence节点返回Succeeded；
- 若全部的下级节点都返回 Failed，则Selector节点返回 Failed；
- 若 Selector 节点下方没有任务节点，返回 Failed；

| 参数名称                             | 参数介绍                             | 说明  |
| -------------------------------- | -------------------------------- | --- |
| Apply Decorator Scope            | 【TRUE】：在行为树重新从Root节点开始前，子装饰器不生效； |     |
| 【FALSE】：在行为树重新从Root节点开始前，子装饰器生效； | 一般是                              |     |

 💡 测试时发现，selector下的同级节点会先判断有装饰器的节点，有符合条件的就优先执行有装饰器的节点，没有符合条件的才会去执行没有装饰器的节点，这个需要验证（因为官方的描述是会从左到右的看哪个符合条件）；

## **Simple Parallel节点**

![[Pasted image 20260415142433.png]]

- 左边紫色的部分，必须连接一个【任务节点】，可称这个任务为“主要任务”；
- 右边灰色的部分可以连【执行选择节点】或者【任务节点】，与“主要任务”并行执行；
- 若“主要任务”返回 Succeeded，则Simple Parallel 节点返回 Succeeded；
- 若“主要任务”返回 Failed，则Simple Parallel 返回 Failed；
- Simple Parallel 的返回结果和并行部分的结果没有关系；

|参数名称|参数介绍|说明|
|---|---|---|
|Finish Mode|【Immediate】：主要任务停止时，并行任务立刻停止；||
|【Delayed】：主要任务停止时，并行任务执行完毕后停止；|||

# 装饰器节点

## **Blackboard Based Condition装饰器**

Blackboard Based Condition 可以进行简单的判断，判断某黑板值是否符合特定值，符合则执行，不符合则不执行；

Observer Aborts的作用（None，Self，Lower Priority和Both）

![[Pasted image 20260415142450.png]]

- **None：**
    - 主动行为：无
    - 被动行为：会将装饰器节点变为一个简单的判断工具，无任何其他作用，但高优先级同级节点的Lower Priority会对其产生影响；
- S**elf：**
    - 主动行为：监听自身，如果自身黑板值不符合装饰器条件，则马上返回上层Selector重新选择；
    - 被动行为：无
- **Lower Priority：**
    - 主动行为：只判断是否符合更高优先级的同层节点的条件；
    - 被动行为：如果有更高优先级的同层节点符合条件且不为Self，则返回selector重新选择；
- **Both：**同时具有Self和Lower Priority的特性；
    - 主动行为：监听自身；
    - 被动行为：监听高优先级，忽略低优先级；
- **特殊注意：**所有的中断行为都可以理解为先返回Selector然后再重新选择，而不是直接转移到其他的逻辑；
