#游戏AI

该文档中，在一般游戏中被称为敌对，中立生物，友好角色的或AI，NPC，的都被统一称为AI



# 写在前面

- 首先AI是在不同的游戏中，甚至不同的阶段都有各自不同的作用，大部分情况下我们无法简单地去拿两个游戏中的AI进行对比，也无法简单的将其他游戏中的AI拿来进行照搬（同样为动作游戏的猎天使魔女和战神就无法进行比较）；
- AI的设计要始终围绕其游戏的核心体验去设计，恐怖游戏的AI就要让玩家感觉到恐怖；动作游戏的AI就要让玩家不断磨练自己的技巧；回合游戏就要让玩家去精进自己的策略头脑；解谜游戏就要让玩家不断地去学习和应用游戏中所给到的所有机制；

# 概述：

## 1) AI的作用：

- 解谜；
- ## 战斗；
    
    - 机制利用；
    - 游戏挑战；
    - 调整游戏节奏；
    - 封锁区域；
    - 帮助玩家；
- 利用；
- 获取；
    - 收益；
    - 图鉴；
    - 有些AI会在交流时透露某些信息；
    - 有些AI会在特定条件下向玩家展现更多的内容，玩法或任务；
- 玩法；
    - 利用AI完成某些玩法；
- 沉浸；
    - 真实多样，行为丰富的AI会让世界更具沉浸感；

## 2) 让AI更有趣：

- **让AI变得更有趣**：可以从以下几个点来出发来考虑如何：
    - 要让玩家觉得AI是危险的,对玩家要产生**威胁**和**挑战**；
    - AI可以**分析战斗的空间**；
    - AI可以形成**配合**，自动编织成**战斗群组**；
    - AI会为自己考虑，会**注意自己的安全**；
    - 让AI能做出一些能让玩家看到的**聪明的决定**；
    - 让AI看起来更有**感情和个性**（个体性格，肢体受伤，元素属性）；
    - 设计一个具象的**仇恨系统**；
- **最多只能有N个AI同时攻击玩家**；
- **种怪技巧**：每场战斗中不同的配比，数量和位置，让战斗更具策略性；
- **AI给玩家相对的动态难度**：让玩家的实际感受好一些；
- **AI要尽可能多的从表现，对话，反应和行为上给玩家反馈**：
    - AI见到玩家会有语言上的反应：AI遇到玩家后有基于概率和状态出现的对话，如下：
        - 敌对阵营AI刚看到玩家会喊：“敌人来啦！大家快做好准备！”并通知附近的同阵营AI；
        - 友军阵营AI刚看到玩家会喊：“向您致敬！尊敬的大人！”；
    - AI见到玩家时的对话会因其他条件所改变，如下：
        - 当玩家完成了拯救世界的任务时，友军阵营的AI会说：“看啊！是我们的救世主！向您致敬！”；
    - **AI的对话可以透露给玩家信息**：玩家可以通过这些玩家的对话知道一些游戏的捷径，或者一些隐藏的秘密；
    - **越简单的AI应该有更低的面数**：经常遇到的敌对AI在设计上就应该有较少的面数，最好是有较多的方形（比如：史莱姆）；

# AI的分类：

### 1) 按照形态分类：

- 人类，犬类，蝎类，节肢类，冷血类，家畜类等等；

### 2) 按照体型分类：

- 超小，小，中，大，巨大，超大；
- 瘦小，中等，粗壮；

### 3) 按照强度分类：

- 弱，中，强，强大；
- 杂鱼，卫士，精英，稀有，传说，Boss；

### 4) 按照战斗类型分类（行为树中设置）：

- 独立，集群；
- All for one（连线怪），One for all（保护怪），技能怪，平A怪，机制怪；

### 5) 按照索敌方式分类（行为树中设置）：

- 被动索敌，主动索敌；
- 视觉索敌，听觉索敌；

### 6) 按照是否有攻击行为分类（行为树中设置）：

- 有攻击行为，无攻击行为；

### 7) 按照是否主动攻击目标分类（行为树中设置）：

- 主动，被动；

### 8) 按照攻击目标分类：

- 结合是否有攻击行为：对部分生物有攻击行为；对部分生物无攻击行为；
- 结合是否主动攻击目标：对部分生物有主动攻击行为；对部分生物有被动攻击行为；

### 9) 按照移动类型分类：

- 直立，飞行，跳跃，爬行；

### 10) 按照攻击距离分类：

- 远程，近战，范围；

### 11) 按照元素类型分类：

- 风，火，雷，冰，时，空，光，暗；

# AI的功能：

### 1) AI的行为：

- **通用：**移动，转向，**记忆**，视觉，听觉，等待；
- **战斗：**技能，死亡，警觉；
- **日常：**说话，睡觉，进食，喝水，交流，坐下，害怕，欢呼，休闲，购买，观看，表演，拾取；
- 不同的行为下，各个值都会有改变（睡觉时索敌的范围变为1；巡逻时索敌范围变为10）；

### 2) AI的能力：

- AI的能力是由于不同的行为组合产生的；
    - 能力包括但不限于：发现，寻找，索敌，呼唤/通知，巡逻，逃跑，躲闪，恢复，攻击，记仇，挑衅，交流，生活，逛街，播放动作；

### 3) 行为树节点：

- AI要支持以下可供策划使用的节点；
    - 记忆；
    - 移动；
    - 等待；
    - 召唤；
    - 随机数；
    - 条件判断（等于，大于，小于，不等于，小于等于，大于等于，有，无）；
        - AI要能判断以下的值：**时间**，**范围**，**概率**，**权重**，**优先级**，**阵营**，**类**；
    - 修改属性；
    - 使用技能；
    - 设立目标；
    - 设立范围；
    - 获取目标属性；
- AI要有以下参数：
    - 性格，体型，强度，属性，生命，物理抗性，元素抗性，暴击，视宽，视距，听觉等等；

### 4) AI的特性：

- **AI具有弱点**：与元素克制和性格不同，弱点是肉眼可见的，如下图所示，左侧的怪无弱点，右侧红圈内为怪弱点；玩家通过远程攻击弱点来造成更大伤害或硬直；

|||
|---|---|
|没有弱点|有弱点|

- **AI具有性格**，例如：胆小，勇敢，狡诈，记仇，谨慎；
    - AI的性格会影响AI的行为和能力；
    - AI的性格会影响AI各个值的范围（勇敢会主动攻击玩家，胆小不会主动攻击玩家）；
- **AI具有习性**，例如：白天睡觉，晚上打猎，怕光，怕火，喜水，喜肉，喜水果，怕人，怕食肉动物，群居，独行等等；
    - 群居类型的生物是否需要做一个战斗群控系统？

### 5) AI的仇恨（记忆）系统：

- AI会记住玩家的行为（比如当玩家经常用箭射骷髅怪，那么骷髅怪就会用盾牌挡住头，玩家需要射骷髅的脚，触发硬直移开盾牌由此**让动态难度更灵活，去目的**）；
- 部分敌对怪被玩家杀掉后复活会害怕玩家，变成中立怪；
- 部分中立怪被玩家杀掉后复活会憎恨玩家，变成敌对怪；
- 可以复活的Boss会记住玩家，如果击败或打跑了玩家，下次遇见的时候会嘲讽玩家，如果被玩家击败，则下次会发出一些愤怒的词语；

# AI的逻辑：

首先AI会被分为**小怪**，**NPC**，和**生物**；

## 1) 小怪逻辑：

- **非战斗状态：**
    - 小怪在非战斗状态下会根据时间来改变，比如白天会出现站岗或巡逻等行为，夜晚会找地方睡觉，白天的下雨天会找地方躲起来；
- **战斗状态：**
    - 小怪发现敌人后可能会呼唤周围的友军，然后冲向目标，进行攻击；
    - 小怪会根据血量多少选择是否继续战斗或者逃跑；
    - 小怪是否会呼唤友军，血量多少时选择逃跑，使用技能频次都和性格，体型，强度，属性有关；
- **参数影响：**
    - **性格：**会决定AI在不同状态下的不同行为和判断（胆小的AI会在血量较高时就逃跑甚至直接逃跑，凶残的AI血量越低，伤害越高，攻击频率越高），以及一些特殊的行为，比如群居的AI在发现玩家时会呼唤附近的AI来协助战斗；
    - **体型：**会决定AI的**外观大小**；
    - **强度：**会决定AI的**奖励回报**；
    - **属性：**会决定AI在不同环境下产生的**特殊行为**，以及受**元素克制**等等；

## 2) NPC逻辑:

- 随机行为NPC：
    - NPC根据提前安排好的路径移动，在移动过程中会遇见可以互动的其他NPC或者物体，遇见后有几率产生互动（与其他NPC的互动要减少一半的几率，以及有双方NPC同时触发交互时的冲突要进行处理优先级）；
    - NPC进行交互时，玩家可以打断其交互；
    - NPC可以与以下物体交互：凳子，水杯，餐桌，杂技摊，商品摊，庄稼，祈祷，基本物品（可以有多种多样的包装，但只用一个动作即可）；
- 预设行为NPC：
    - NPC会根据预设的路线以及特殊的地点去进行特殊的动作，玩家可以打断其动作；
- 固定位置NPC：
    - NPC会站在原地不动，可以进行交互（多见 于某些重要的NPC）；

## 3) 生物逻辑:

- 生物是中立的，玩家和小怪都可以攻击中立生物；
- 生物是介于NPC与AI之间的，生物在非战斗状态下，会更像NPC，在战斗时就成为了小怪；

# 1.        什么是Boss：

|   |
|---|
|巨大的或者极富挑战性的敌人，阻碍玩家的进程，在每一关或整个游戏的高潮或（结尾）时出现；|

---

# 2.        玩家攻略Boss的行为和套路：

|   |
|---|
|l  不要让玩家离boss太远的时间过长；<br><br>l  要让玩家**动起来**；<br><br>l  **已掌握的行动**；<br><br>l  **新能力**（对新能力的应用，以及新的能力对于这个boss有作用，很多游戏都是例如：某个boss怕火，玩家用火烧死这个boss之后发现火能这样用之类的）；<br><br>l  **已掌握的行动与新能力的组合**；|

---

# 3.        Boss带给玩家的体验：

|   |
|---|
|l  boss的**外观**要让玩家觉得无法被击倒；<br><br>l  boss在剧情中是与玩家敌对的**最大障碍**与威胁，不消灭boss，剧情就无法继续；<br><br>l  boss与杂兵不同，并不是为体现玩家强大而设置的敌人，要表现出不消灭玩家不罢休的心态，让玩家感受到**实质上的威胁**（即使被打的就剩下骨头架子，也有新的攻击方式）；<br><br>l  boss要出其不意（**出乎玩家意料**的行为或攻击，令玩家吃惊）；<br><br>l  boss要具备“惧怕特定武器”或“攻击时有破绽”等**弱点**；<br><br>l  boss要让玩家切实感受到自身的**成长**；<br><br>l  boss被消灭后，玩家将获得巨大的**成就感**；<br><br>l  一定要让玩家给boss**最后一击**；<br><br>l  boss要和玩家有怎么样的战斗关系：身体对抗者？脑力对抗者？<br><br>l  是什么让Boss成为值得一战的对手？（确保玩家在大战开始前就要知道他们所要面临的巨大挑战）；<br><br>l  打败boss，主角能获得什么？（宝藏？武器？力量？救赎？）；|

# 4.         Boss故事上的设定：

|   |
|---|

# Ai：

l  内在决定外在，功能决定形态；

l  设计敌人时要让敌人各有千秋，互相配合；

l  仔细平衡敌人的强度、速度和体积；

l  和敌人的战斗要有趣；

l  敌人是用来打的，不是用来躲的；

l  并不是敌人的每一下攻击都得造成伤害；

l  需要让玩家憎恨敌人；

l  使用动态难度帮助或遏制玩家；

l  设计1大块头的boss需要注意摄像机的问题；

l  Boss战发生的地点和设计boss战本身一样重要；

l  让玩家给boss致命一击；

l  除了大块头的狂躁怪物，还有其他类型的敌人；

l  多强调戏剧性，而不是排场；

# 机关：

机关大致有四种类型：机关、陷阱、小道具、谜题；

陷阱一定要让玩家看到时就知道其危险性；

死亡永远不是教育玩家最好的方式，这只会让玩家感到沮丧；

陷阱要有固定的移动路径，要让玩家能掌握其运动规律；

穿过陷阱的时机要可以预判；

穿过陷阱的最佳时机不能太长；

利用游戏世界中“暗藏的玄机”给玩家线索，让他们知道站在哪是安全的，站在哪是危险的；

有些机关纯属是为了好玩，比如可以演奏的钢琴，可以挑逗的小狗之类的，可以大胆的加入这些纯乐趣机关；

组合技巧：

跳过危险的区域，但区域的另一侧有敌人在等着；

让敌人恰好在机关移开时露出破绽；

诱导敌人触发陷阱；

 推箱子：

移开箱子，开门

移开箱子当跳板

移开箱子触发开关

移开箱子挡住火焰喷射器

推箱子下水做成路；

按照顺序推箱子；

箱子后面躲着；

箱子挡箭牌；

箱子砸人；

机关最好设计有三个等级：

1.打开道路；

2.利用机关；

3.更高级的玩法获得隐藏的道具；
