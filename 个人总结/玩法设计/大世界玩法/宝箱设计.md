# 宝箱设计

## 核心定位

宝箱不只是“领奖励的盒子”，它在大世界里承担三个作用：

- **吸引玩家**：远处能看到，靠近后有反馈。
- **解释场景**：让玩家知道它为什么在这里。
- **制造小目标**：发现、接近、解锁、获得奖励。

一个好宝箱要让玩家产生这三个问题：

- 这里有什么？
- 我要怎么拿到？
- 拿到以后值不值得？

## 一、外观设计

### 1. 符合世界观

宝箱外观要贴合游戏题材，不要直接套传统宝箱。

- **末世题材**：废弃车辆后备箱、保险柜、医疗箱、军用补给箱。
- **科幻题材**：补给无人机、墙面急救包、能量舱、货运箱。
- **奇幻题材**：古代宝箱、封印石台、魔法阵、遗迹机关。

奖励也不一定要放在箱子里。强力装备本身就能作为视觉目标，比如：死去士兵旁边的原型武器。

### 2. 分清等级

奖励载体需要有档位区分，让玩家能一眼判断价值。这里以“传统宝箱”为例：

| 档位 | 外观特征 | 玩家预期 |
|---|---|---|
| 普通 | 木箱、旧箱、小体积 | 基础资源 |
| 稀有 | 金属、锁具、明显装饰 | 更好的道具 |
| 高级 | 特效、独特造型、复杂结构 | 稀有装备或关键奖励 |

可用的区分方式：颜色、材质、大小、装饰复杂度、光效强度、音效稀有度。

### 3. 暗示奖励内容

宝箱外观最好能暗示里面是什么。

- 医疗箱 → 治疗道具。
- 武器箱 → 武器、弹药。
- 工具箱 → 制造材料。
- 魔法封印箱 → 法术、符文、稀有资源。

这样玩家会逐渐建立经验：看到某类宝箱，就知道大概能获得什么。

## 二、状态表现

宝箱至少需要区分三种状态：

| 状态 | 表现重点 | 目的 |
|---|---|---|
| 未开启 | 发光、高光、提示图标、轻微动画 | 吸引玩家 |
| 上锁 | 锁链、封印、电流、机关连线 | 告诉玩家暂时打不开 |
| 已开启 | 箱盖打开、光效消失、内容变空 | 避免重复误判 |

### 上锁表现要说明原因

不要只告诉玩家“打不开”，还要暗示“为什么打不开”。

- 需要电力：宝箱上有电力标识、断开的电缆、电流特效。
- 需要钥匙：明显的锁孔、锁链、钥匙图标。
- 需要击败敌人：宝箱和敌人之间有封印线、护盾或区域锁。
- 需要解谜：宝箱附近有机关、符文、终端或可互动装置。

## 三、交互方式

不要所有宝箱都做成“长按 F 开启”。如果没有情境，这种交互会很机械。

交互方式应该和宝箱类型匹配：

| 宝箱类型 | 交互方式 | 体验重点 |
|---|---|---|
| 废弃车后备箱 | 连点、撬开、拉拽 | 有阻力感 |
| 玻璃展柜 | 攻击打碎玻璃 | 直接、爽快 |
| 被封印宝箱 | 解谜、点亮机关 | 探索感 |
| 敌人看守宝箱 | 击败敌人后开启 | 战斗奖励 |
| 科技补给箱 | 接电、破解终端 | 题材匹配 |

如果要加入小游戏，最好控制在很短时间内，不要打断探索节奏。

## 四、周围环境

宝箱不要孤零零地放在地上。周围环境要解释它的存在。

可以从这几个问题入手：

- 谁把宝箱放在这里？
- 它是被藏起来的，还是被挖出来的？
- 它为什么还没有被拿走？
- 玩家靠近时会先看到什么？

### 环境叙事例子

- 宝箱周围有坑、铲子、绳索、营地。
	- 暗示有人刚把它挖出来。
- 宝箱旁边有尸体、武器、战斗痕迹。
	- 暗示这里发生过争夺。
- 宝箱被怪物围住。
	- 暗示奖励需要通过战斗获得。
- 宝箱放在高台、洞穴深处、废墟中心。
	- 用地形强化“这是一个目标点”。

## 五、宝箱的探索节奏

一个宝箱从出现到领取，可以拆成一个小循环：

1. **发现**：玩家从远处看到光效、轮廓、地形或敌人。
2. **接近**：玩家判断有没有危险、有没有路径。
3. **理解**：玩家看懂宝箱状态，知道是否需要钥匙、战斗或解谜。
4. **完成条件**：玩家击败敌人、解开机关、找到钥匙。
5. **领取奖励**：宝箱打开，给出清晰反馈。
6. **清理状态**：宝箱变为已开启，地图提示消失。

这个循环越清楚，玩家越不容易困惑。

## 六、奖励设计知识点

### 1. 奖励要匹配投入

玩家付出的成本越高，奖励预期就越高。

- 只是路边顺手打开 → 小奖励即可。
- 需要绕路探索 → 奖励要更好。
- 需要战斗或解谜 → 奖励必须明显高于普通宝箱。
- 需要完成一条支线 → 可以给稀有物品或长期成长资源。

### 2. 奖励要有即时反馈

打开宝箱后，玩家需要立刻感到“拿到了东西”。

可用反馈：

- 掉落飞入背包。
- 稀有物品特写。
- 音效升级。
- UI 列出奖励。
- 高价值奖励有特殊动画。

### 3. 避免奖励污染

不要让所有宝箱都塞一堆无关物品。奖励太杂，玩家会失去预期。

更好的做法：

- 按宝箱类型控制奖励池。
- 按区域等级控制价值。
- 按探索难度控制稀有度。
- 少量随机 + 部分保底，避免玩家空手而归。

## 七、常见问题

- **宝箱太像场景物件**：玩家看不出来能互动。
- **光效太强**：破坏场景氛围，显得廉价。
- **上锁原因不清楚**：玩家不知道下一步该做什么。
- **奖励和难度不匹配**：玩家会觉得被欺骗。
- **已开启状态不明显**：玩家会反复跑回来看。
- **宝箱摆放没有理由**：场景显得像“策划硬放”。

## 八、设计检查清单

- [ ] 外观是否符合游戏题材？
- [ ] 玩家远处能否注意到它？
- [ ] 宝箱等级是否能一眼区分？
- [ ] 外观是否暗示奖励类型？
- [ ] 上锁原因是否清楚？
- [ ] 交互方式是否符合宝箱类型？
- [ ] 周围环境是否解释了宝箱来源？
- [ ] 奖励是否匹配玩家投入？
- [ ] 打开后的反馈是否足够明确？
- [ ] 已开启状态是否不会被误认为未开启？
